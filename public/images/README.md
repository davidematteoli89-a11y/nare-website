# Struttura immagini

- `cristina/` — ritratti e foto editoriali di Cristina (Fase 2+, foto reali fornite dal cliente, no stock).
- `editorial/` — foto ricette/autoproduzioni/casa/botanica per card e hero (Fase 2+, foto reali).
- `rai/` — poster/thumbnail degli interventi RAI, solo dopo verifica diritti d'uso (vedi Fase 0, punto 8).
- `placeholders/` — placeholder locali neutri e chiaramente temporanei, usati finché non esistono foto reali. Nessuna immagine stock generica o generata via AI in questa fase.
